# FOPII-Group-5-Project

## Project Title
Gebar Commercial Bank Management System

This project is a C++ banking management system. It uses SQLite3 as its database. The system has two roles: Admin and User. The Admin can do a lot of things like manage the core banking data. This includes things like branches and customers and employees and accounts and loans and transactions. The Admin does all this through a menu-driven interface. The User can log in with their account number and password. When the User logs in they can view their account details. Check their transaction history. They can also do deposits or withdrawals. All this is automatically logged in the database.

Each record is given an ID. This ID is generated automatically. The records include things like branches, customers, employees, accounts, loans and transactions. This unique ID helps to keep everything traceable. The C++ banking management system shows how to build a database-driven application in C++. It also shows how to do role-based access and CRUD operations and transaction management. This makes it really useful for people who want to learn how to use SQL with C++ in a way. It also shows what real-world banking workflows are like. The system is a way to learn about the integration of SQL with C++ and it is also good, for simulating real-world banking workflows.
